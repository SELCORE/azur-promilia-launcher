# 아주르 프로밀리아 런처 (무료 Wine + DXMT, 실험 단계)

CrossOver 없이 무료 Wine과 DXMT로 넥슨 플러그와 아주르 프로밀리아(한국 PC판)를 Apple Silicon 맥에서 돌리는 비공식 런처예요. Wine은 CodeWeavers가 공개한 CrossOver 소스로 이 저장소에서 직접 빌드해서 배포해요.

> **비공식 실험 프로젝트예요.** 넥슨, 만쥬, CodeWeavers와 관련이 없어요.
> 넥슨은 macOS와 Wine을 지원하지 않아요. 계정 제재 등의 위험은 본인 책임이에요.
> 넥슨 파일은 이 저장소에 없어요. 실행할 때 넥슨 공식 서버(`platform.nexon.com`)에서 받아요.

https://youtu.be/msRSRG-WunI

## 지금 상태 (2026-11-27 기준)

| 항목 | 결과 |
|---|---|
| 직접 빌드한 Wine + DXMT 런타임 자동 다운로드 (체크섬 확인) | 됨 |
| 넥슨 플러그 화면 표시, 로그인 | 됨 |
| CrossOver에 받아 둔 게임을 "설치 완료"로 인식 | 됨 (다시 받지 않고 연결) |
| 게임 실행 파일: DXMT 그래픽, 넥슨 보안(NGS-X) 초기화 | 됨 (자체 빌드 런타임에서 3번 중 3번) |
| WebView2 자동 설치 (Microsoft 공식 설치 프로그램, 109 버전) | 됨 |
| CrossOver 없이 넥슨 플러그에서 게임 설치 시작 | 됨 (NGM이 WebView2를 띄우고 다운로드 시작까지 확인) |
| 넥슨 플러그에서 게임 실행 | 됨 (오픈 당일 시작 화면 약 55fps, Metal HUD 기준) |
| 게임 안 한글 표시 | 됨 (런처가 한글 글꼴을 넣어 줘요) |
| 한글·영문 키보드 입력 (넥슨 플러그) | 됨 (자체 빌드 런타임) |
| 게임 단축키를 영문 자판 기준으로 표시, 게임이 맥 입력 소스를 바꾸지 않음 | 됨 (런타임 p2부터) |
| 게임 채팅 한글 조합, 한국어 입력 상태에서 이동·ESC | 됨 (런타임 p5, 게임에서 확인) |
| macOS 게임 모드 | 됨 (런타임 p4부터, 게임에서 확인) |
| 게임 중 맥 전체가 멈추는 GPU 문제 | 고침 (런타임 p6, 고친 DXMT. 15분 플레이에서 재현 없음) |
| 브라우저 로그인(구글, 애플 등) 뒤 "앱으로 돌아가기" | 고침 (런처 0.4.3. 구글 로그인 결과가 넥슨 플러그까지 가는 것 확인) |

게임 실행 파일은 런처를 거치지 않고 직접 켜서 확인했어요. 로그인 정보가 없어서 로그인 SDK 단계(오류 10121)에서 꺼지는 게 정상이에요. CrossOver에서도 같은 단계까지 가요.

**테스트 환경:** MacBook Pro (M5 Pro, 24GB), macOS 27.0.1, Wine (CrossOver 26.3 공개 소스로 직접 빌드), DXMT v0.80

## 쓰는 법

### 앱 받아서 쓰기 (쉬운 방법)

1. [Releases](https://github.com/SELCORE/azur-promilia-launcher/releases)에서 `Azur-Promilia-Launcher.zip`을 받아 압축을 풀어요.
2. `Azur Promilia Launcher.app`을 응용 프로그램 폴더로 옮겨요.
3. 앱을 열어요. 처음에는 Apple 인증이 없는 앱이라 열리지 않아요.
   - **시스템 설정 > 개인정보 보호 및 보안**에서 맨 아래 **그래도 열기**를 누르세요.
   - 한 번만 하면 돼요.

### 직접 빌드하기

```bash
git clone https://github.com/SELCORE/azur-promilia-launcher.git
cd azur-promilia-launcher
./build-app.sh            # dist/Azur Promilia Launcher.app 이 만들어져요 (Xcode 명령줄 도구 필요)
                          # 넥슨 플러그 최소화 도우미(plugmin.exe)는 mingw-w64가 있을 때만 들어가요: brew install mingw-w64
open "dist/Azur Promilia Launcher.app"
```

### 처음 실행하면

확인 창이 뜨고 준비를 시작해요. 인터넷 속도에 따라 몇 분 걸려요.

1. 이 저장소의 릴리스에서 Wine + DXMT 런타임(약 296MB)을 받아요.
   - 받은 파일은 체크섬으로 확인해요.
2. NGM에 필요한 WebView2 런타임을 Microsoft 공식 설치 프로그램으로 설치해요 (약 150MB).
   - 최신 버전은 Wine에서 잘 돌지 않아서, 설치하는 동안만 윈도우 버전을 Windows 7로 알려서 109 버전을 받아요.
   - 이 버전으로 고정되게 자동 업데이트를 꺼요.
3. 넥슨 공식 서버에서 넥슨 플러그와 NGM을 받아요.
4. 검은 화면 방지와 창 설정을 적용해요.
5. CrossOver의 `Azur Promilia` 보틀이 있으면 WebView2를 받지 않고 거기서 복사하고, 받아 둔 게임도 다시 받지 않고 APFS 복제로 가져와요 (추가 공간은 거의 안 써요).

**두 번째부터는** 앱을 열면 넥슨 플러그가 바로 켜져요.

모든 파일은 `~/Library/Application Support/Azur Promilia Launcher/`에 저장돼요.

| 폴더 | 내용 |
|---|---|
| `wine/` | Wine 본체 (DXMT 포함) |
| `prefix/` | 윈도우 환경 (C 드라이브) |
| `logs/` | 준비·실행 기록 |

## 설정

런처 창에서 바꿀 수 있어요. 다음에 넥슨 플러그를 켤 때 적용돼요 (넥슨 플러그가 게임을 켜면서 그대로 이어져요).

| 설정 | 하는 일 |
|---|---|
| Metal HUD | 게임 화면 위에 FPS와 GPU 정보를 표시해요 |
| Retina 모드 | 맥 화면의 원래 해상도로 그려요. 선명하지만 훨씬 무거워져요 |
| 왼쪽 CMD를 CTRL로 할당 | 왼쪽 ⌘ 키를 Ctrl 키로 써요 |
| 게임 안 한글 입력 | 맥 입력 소스가 한국어일 때 게임 채팅에 완성된 한글을 넣어요 (기본 켜짐) |
| macOS 게임 모드 | 게임을 macOS가 게임 앱으로 알아보게 해서, 전체 화면일 때 게임 모드(CPU·GPU 우선, 백그라운드 작업 줄이기)를 받아요. 활성 상태 보기에도 `wine` 대신 `AzurPromilia.exe`처럼 프로그램 이름이 나와요 (기본 켜짐, 런타임 p4부터) |
| 게임 중 넥슨 플러그 최소화 | 게임이 켜지면 넥슨 플러그 창을 최소화해요. 넥슨 플러그는 뒤에 있어도 화면을 계속 그려서 CPU를 50~60% 써요. 최소화하면 0%가 돼요. Dock에서 다시 열 수 있어요 (기본 켜짐) |
| AVX2 명령어 (Rosetta) | Rosetta가 게임에 AVX/AVX2/FMA를 알려서, 게임의 Unity Burst 코드가 SSE2 대신 AVX2 버전으로 돌아요. M5 Pro 필드에서 FPS 중간값이 64에서 67로 올랐어요. 게임이 자주 튕기면 꺼 보세요 (기본 켜짐) |
| 사용자 정의 해상도 | 넥슨 플러그를 켤 때마다 게임 해상도를 이 값으로 맞춰요 (게임 안 설정보다 우선) |
| 사용자 지정 모니터 주사율 | 게임 주사율과 DXMT 프레임 상한을 이 값으로 맞춰요. FPS가 60 아래로 묶일 때 켜세요 |

터미널에서는 `./azurctl.sh settings`로 보고, `./azurctl.sh set metal_hud 1`처럼 바꿔요.


## 터미널 명령어

| 명령어 | 하는 일 |
|---|---|
| `./azurctl.sh setup` | 모두 준비해요. 옵션: `--runtime-from <tar.xz>`, `--webview2-from <폴더>`, `--import-crossover <보틀>` |
| `./azurctl.sh detect-sources` | CrossOver 보틀에서 재사용할 수 있는 WebView2와 게임을 찾아 setup 옵션으로 출력해요 |
| `./azurctl.sh plug` | 넥슨 플러그를 켜요 |
| `./azurctl.sh stop` | 이 런처의 Wine 프로세스를 모두 종료해요 |
| `./azurctl.sh status` | 설치 상태를 보여줘요 |
| `./azurctl.sh import-crossover [보틀]` | CrossOver 보틀에 받아 둔 게임을 APFS 복제로 가져와요 |
| `./azurctl.sh game-direct` | 넥슨 플러그 없이 게임 실행 파일만 켜 봐요 (그래픽·보안 모듈 확인용) |
| `./azurctl.sh download-status` | 게임 다운로드 상태 (받는 중, 멈춤, 끝남) |
| `./azurctl.sh report` | 문제 보고 내용을 출력해요 (토큰, 이메일, 사용자 이름은 가려요) |
| `./azurctl.sh open-url <ngm://... \| nexonplug://...>` | 브라우저 로그인 결과 링크를 넥슨 플러그에 넘겨요. 보통은 런처 앱이 Safari에서 받아 알아서 불러요 |
| `./azurctl.sh uninstall --keep-game` / `--all` | 런처를 지워요. `--keep-game`은 받은 게임을 남겨서 다시 준비할 때 그대로 써요 |

## 문제가 생기면

1. 런처 창의 **문제 보고**를 눌러요. 상태와 로그 끝부분이 클립보드에 복사되고, GitHub 이슈 양식이 열려요.
   - 로그인 토큰, 이메일, 맥 사용자 이름, 넥슨 회원 번호는 자동으로 가려져요. 올리기 전에 한 번 훑어봐 주세요.
2. 양식의 "런처 보고 내용" 칸에 붙여 넣고(⌘V) 증상을 적어 [이슈](https://github.com/SELCORE/azur-promilia-launcher/issues)로 올려 주세요.

런처를 켜면 새 버전이 있는지 확인해서, 있으면 창 위쪽에 알려줘요.

## 알려진 문제

- **브라우저 로그인 뒤 "앱으로 돌아가기"에서 Safari가 "주소가 유효하지 않음" (0.4.3에서 고침)**
  - 구글, 애플 같은 계정으로 로그인하면 넥슨 플러그가 브라우저를 열고, 로그인이 끝나면 `ngm://` 링크로 돌아와요.
    Windows에서는 이 링크를 NGM이 받아서 넥슨 플러그에 넘기는데, 맥에는 받을 앱이 없었어요. (일본 쪽 로그인은 `nexonplug://`를 써요.)
  - 0.4.3부터 런처 앱이 두 링크를 받아서 Windows에서처럼 NGM(또는 넥슨 플러그)에 넘기고, 넥슨 플러그를 앞으로 꺼내요.
    넥슨 플러그가 꺼져 있으면 켜면서 넘겨요.
  - 처음 한 번은 Safari가 "아주르 프로밀리아 런처를 열까요?"라고 물어요. **허용**을 눌러 주세요.
  - 처음 받을 때는 NGM이 자기 파일을 내려받느라 1분쯤 걸릴 수 있어요.
  - 넥슨 플러그가 "회원가입 대기 상태"처럼 계정 안내를 띄우면 로그인 결과는 제대로 넘어간 거예요. 안내대로 넥슨닷컴에서 처리해 주세요.
  - 링크에 로그인 토큰이 들어 있어서 런처는 화면이나 기록에 남기지 않아요.
  - 맥용 넥슨 플러그를 함께 설치했다면 macOS가 링크를 그쪽으로 보낼 수 있어요. 그때는 런처 쪽 넥슨 플러그의 **넥슨 로그인**(아이디, 비밀번호)을 써 주세요.
- **일회용 로그인에서 "로그인에 실패했습니다"**
  - 휴대폰에는 로그인 알림이 오는데 넥슨 플러그는 실패로 보여 준다는 제보가 있어요. 아직 원인을 찾지 못했어요.
  - 그동안은 **넥슨 로그인**(아이디, 비밀번호)이나 브라우저 로그인(0.4.3 이상)을 써 주세요.
    다시 나면 오류 창을 찍은 화면과 **문제 보고** 내용을 이슈로 보내 주세요.
- **넥슨 플러그가 "Nexon Plug Error (2)"에서 멈춤**
  - 넥슨 플러그는 켜질 때 `assets-nxplug.nexon.com`에서 화면을 받아요. 이 주소를 막는 네트워크(학교·회사 와이파이 등)에서는 이 오류에서 멈춰요.
  - 다른 네트워크(집 와이파이, 휴대폰 핫스팟)에서 켜 보세요. 런처 문제는 아니에요.

- **게임 다운로드가 중간에 멈춤**
  - Wine에서 넥슨 다운로더가 가끔 중간에 멈추고 NGM이 꺼져요. 받은 부분은 남아 있어요.
  - 런처 창이 이걸 알아채서 알려줘요. 넥슨 플러그에서 **설치(이어받기)** 를 다시 누르면 이어서 받아요.

- **게임 안 글자가 깨지던 문제 (해결)**
  - 게임 일부 화면이 윈도우 글꼴(MiSans, Noto Sans S Chinese, 맑은 고딕)을 찾는데 Wine에는 없어서 한글이 빠져 보였어요.
  - 런처가 맥에 있는 한글 글꼴(AppleGothic)을 그 이름으로 복사해 Wine 글꼴 폴더에 넣어요. 이 맥 안에서만 쓰는 복사본이에요.
- **"게임 실행에 실패했습니다"가 뜨는데 게임은 켜지던 문제 (해결)**
  - NGM이 Wine에서 켜지지 않는 "Nexon Launcher" 서비스를 기다리느라 늦어져서 넥슨 플러그가 실패로 판단했어요.
  - 런처가 넥슨 플러그를 켤 때 이 서비스를 꺼 둬서, NGM이 바로 게임을 켜요.
- **넥슨 플러그가 안 켜지거나 1분 가까이 걸리던 문제 (0.4.4에서 고침)**
  - NGM이 실행될 때(브라우저 로그인 등) 이 서비스를 다시 자동 시작으로 등록해요. 그러면 Wine을 처음 켤 때마다 서비스를 40초쯤 기다렸어요.
  - 0.4.3까지는 런처가 이 서비스를 레지스트리에서 찾지 못해 끄지 못했어요(Wine은 `ControlSet001` 아래에 적어 둬요).
  - 0.4.4부터는 Wine을 켜기 전에 레지스트리 파일에서 바로 꺼 둬서, 넥슨 플러그가 몇 초 만에 떠요.

- **DXMT 초기화 중 튕김 (예전 버전)**
  - 예전 런타임(DXMT 654f547)에서는 게임을 켜자마자 `NSInvalidArgumentException` 오류로 가끔 꺼졌어요.
  - 지금 런타임(DXMT v0.80)에서는 3번 시험해서 한 번도 나지 않았어요. 다시 나면 알려 주세요.
- **키보드 입력**
  - 넥슨 플러그에서는 한글과 영문 입력이 모두 잘 돼요 (CrossOver 26.3 소스 빌드부터).
  - 게임은 자기 창의 Windows IME를 꺼 둬서, 맥이 한국어 입력 상태면 자모가 떨어져 쳐지고 단축키가 ㅓ/ㅣ처럼 보였어요.
    게임이 켜질 때 맥 입력 소스를 한국어로 바꾸기도 했어요.
  - 런타임 p2부터 이렇게 고쳤어요 ([`runtime/patches/apply.py`](runtime/patches/apply.py)).
    - 단축키와 키 이름은 늘 영문 자판(ABC) 기준이에요.
    - 게임이 맥 입력 소스를 바꾸지 못해요.
    - 게임 창의 키를 맥 한글 입력기에 먼저 보내고, 완성된 글자를 게임에 넘겨요. 조합 중인 글자는 다음 글자를 치거나 스페이스·Enter를 누를 때 나타나요.
    - 이동키를 꾹 누를 때는 입력기를 거치지 않고(p3), ESC는 늘 게임으로 바로 가요(p5).
  - 런처 설정의 **게임 안 한글 입력**을 끄면 한국어 입력 상태에서도 게임에 영문이 쳐져요.
- **CrossOver에서 가져온 게임 (예전 버전 주의)**
  - 0.3.1까지는 게임을 링크로 연결해서, 한쪽에서 게임을 지우면 다른 쪽 게임까지 지워졌어요.
  - 지금은 APFS 복제로 따로 된 사본을 만들어서, 한쪽을 지워도 다른 쪽은 남아요.
- **넥슨 플러그 창 표시**
  - 소프트웨어 렌더링 옵션(`--use-gl=swiftshader --use-angle=swiftshader --in-process-gpu`)으로 켜요. 그래야 화면이 나와요.
  - 그래서 넥슨 플러그 창이 열려 있는 동안 CPU를 50~60% 써요. Wine은 창이 가려진 걸 알려 주지 않아서, 게임을 전체 화면으로 해도 계속 써요.
  - 0.4.5부터 게임이 켜지면 런처가 넥슨 플러그 창을 최소화해요(설정의 **게임 중 넥슨 플러그 최소화**). 그러면 0%가 돼요. M5 Pro 전투 장면에서 FPS가 51.6에서 53.7로 올랐어요.
  - Wine에서는 게임이 켜진 뒤에도 넥슨 플러그가 "게임 실행에 실패했습니다"를 띄울 수 있어요. 게임은 정상이니 **확인**을 누르면 돼요.
- **게임 중 맥 전체가 멈춤 (런타임 p6에서 고침)**
  - DXMT v0.80의 GPU 셰이더 버그 때문에, 지오메트리 셰이더를 쓰는 장면에서 GPU가 수십 초 멈추고 화면 전체가 굳었어요. 이때는 강제로 꺼야 했어요 ([3Shain/dxmt#200](https://github.com/3Shain/dxmt/issues/200)).
  - 런타임 p6은 DXMT v0.80에 개발자의 수정(aadf0fb, 46911d7)과 이슈의 안전장치를 넣어 직접 빌드해요 ([`runtime/patches/dxmt-apply.py`](runtime/patches/dxmt-apply.py)).
- **게임이 중간에 잠깐씩 멈춤**
  - 처음 보는 장면이나 이펙트가 나오면 셰이더를 Metal용으로 바꾸고 컴파일하느라 잠깐 멈춰요. 한 번 본 것은 캐시에 남아서 다음부터는 덜 멈춰요.
  - 게임 안 넥슨 공지나 웹 창을 처음 열 때도 잠깐 멈춰요.
  - 계속 자주 멈추면 **활성 상태 보기**에서 CPU를 많이 쓰는 프로세스를 확인해 주세요. 개발하는 동안 macOS의 `PerfPowerServices`가 CPU 코어 2개를 계속 쓰는 일이 있었어요. `sudo killall PerfPowerServices`(맥 암호 필요)나 재시동으로 풀렸어요. **문제 보고**에도 CPU 상위 프로세스가 들어가요.

## 런타임 직접 빌드하기

GitHub Actions의 **build-runtime** 워크플로를 실행하면 Wine + DXMT 런타임이 만들어져요. 맥에서 직접 빌드하려면 이렇게 하세요.

```bash
WORK="$HOME/azur-runtime-build" runtime/build-runtime.sh all    # 결과: $HOME/azur-runtime-build/out/azur-runtime-*.tar.xz
./azurctl.sh setup --runtime-from "$HOME"/azur-runtime-build/out/azur-runtime-*.tar.xz
```

- `WORK` 경로에 공백이 있으면 빌드가 실패해요 (`~/Library/Application Support` 같은 곳은 피하세요).
- 빌드한 Wine을 아주 긴 경로(약 250자)에 풀면 Wine이 바탕 화면 창을 만들지 못하고 explorer.exe를 계속 띄워요. 런처는 짧은 경로에 설치하니 상관없지만, 직접 시험할 때는 짧은 경로를 쓰세요.

## 제거

1. 런처 창의 **지우기…** 를 눌러요.
   - **게임은 남기고 지우기:** Wine, 넥슨 플러그, 설정, 기록만 지워요. 다시 준비하면 남겨 둔 게임을 그대로 써요.
   - **게임까지 모두 지우기:** 게임(약 82GB)까지 지워요. 되돌릴 수 없어요.
2. 앱은 응용 프로그램 폴더에서 휴지통으로 옮겨요.
